Formalizing value matrix computation in attention

November 11, 2026 · Muyu He

We can always write the output of attention as the sum across heads of the weighted average of each token under a linear transformation \(W_{o,i} \ W_{v,i}\) at head \(i\). Formally, the contribution of a single token \(x\) to the attention output is:

$$ \begin{gathered} \sum_{i}^{n\_\text{head}} \left( W_{o,i} \ (\text{attn}_i \cdot W_{v,i} \ x) \right) \\ = \sum_{i}^{n\_\text{head}} \text{attn}_i \cdot \left( W_{o,i} \ W_{v,i} \ x \right) \end{gathered} $$

Low-rank parametrization. This means that equivalently, we can see attention as follows: before each token's information \(x\) is weighted averaged within head by attention and then summed across head, it goes through a single low rank matrix \(W_{o,i}' = W_{o,i} \ W_{v,i}\). This means it does an one-time rotation in a low rank space, where the rotation depends on interactions across all dimensions in \(x\) by virtue of matrix-vector multiplication. Since we have \(n\_\text{head}\) of these rotations, the composite rotation is again full-rank in \(\text{head}\_\text{dim} \times n\_\text{head} = \text{hidden}\_\text{dim}\).

Variant 1: Sharing the rotation across heads. Alternatively, then, we can simply define a single, shared \(W_o\) across heads, so all heads share the same channel-dependent rotation. Since \(W_o\) is not parametrized by a pair of rectangular matrices, it is not low-rank. So the rotation will happen in full-rank hidden space. Formally:

$$ \begin{gathered} \sum_{i}^{n\_\text{head}} \text{attn}_i \left( W_o \ x \right) \\ = W_o \ x \ \sum_{i}^{n\_\text{head}} \text{attn}_i \end{gathered} $$

As \(W_o\) is shared, the attention operation is reduced to just summing \(x\)'s attention scores across heads and scaling a one-time linear transformation \(W_o \ x\).

Variant 2: Reintroducing head-specific rotation. The limitation of using a single, shared \(W_o\) is that there is no head-specific rotation of \(x\), which was made possible by \(W_v\). If we do not want to reintroduce the matrix \(W_v\), we can instead introduce a scaling vector per head, \(v_{\text{scale}}\), to do element-wise multiplication with \(x\). This enables a head-specific rotation of \(x\), with the caveat that the rotation does not depend on interactions across dimensions in \(x\). Formally:

$$ \sum_{i}^{n\_\text{head}} \text{attn}_i \cdot \left( W_{o} \ ( v_{\text{scale},i} \odot x ) \right) $$

The tradeoff is that in this formulation, the FLOPs unfairly increases from the baseline. For each head, rather than computing the low-rank transformation \((W_{o,i} \ W_{v,i} \ x)\) in \([\text{d}\_\text{hidden} \rightarrow \text{d}\_\text{head} \rightarrow \text{d}\_\text{hidden}]\), it instead computes the full-rank transformation \((W_{o} \ ( v_{\text{scale},i} \odot x ))\) in \([\text{d}\_\text{hidden} \rightarrow \text{d}\_\text{hidden} \rightarrow \text{d}\_\text{hidden}]\).

Variant 3: To maintain or even reduce FLOPs in the \(v_{\text{scale}}\) design, we can partition the input \(x\) into \(n\_\text{head}\) chunks. Each head gets its chunk and a \(v_{\text{scale}}\) in \(\text{d}\_\text{head}\). Each head chunk eventually goes through the same rectangular \(W_o\) of shape \((\text{d}\_\text{hidden} \times \text{d}\_\text{head})\). Formally:

$$ \sum_{i}^{n\_\text{head}} \text{attn}_i \cdot \left( W_{o} \ ( v_{\text{scale},i} \odot x_{[i:i+1]} ) \right) $$

So in total, for each head, \(x\) goes through two rotations: a head-specific, channel-independent rotation first, and a head-general, channel-independent rotation second, both in \(\text{d}\_\text{head}\).
